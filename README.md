# 📚 Entre Líneas

**Entre Líneas** es un sitio web estático desarrollado como proyecto para la materia **Taller Integrador II**.

El proyecto representa una **librería online**, donde los usuarios pueden explorar diferentes libros, conocer información sobre ellos y acceder a una sección de contacto.

El objetivo principal del proyecto fue aplicar mis conocimientos de **HTML5, CSS3 y Bootstrap**, creando un sitio visualmente atractivo, organizado y adaptable a distintos tamaños de pantalla.

## 🎯 Objetivo

Desarrollar un sitio web estático y responsivo que represente una librería online, aplicando buenas prácticas de estructura, navegación y diseño web.

Con este proyecto busqué integrar:

* Estructura semántica mediante HTML.
* Estilos personalizados mediante CSS.
* Componentes y sistema responsive de Bootstrap.
* Navegación entre diferentes páginas.
* Formularios.
* Imágenes y contenido visual.
* Diseño adaptable a dispositivos móviles y de escritorio.
* Control de versiones mediante Git y GitHub.
* Publicación del proyecto mediante Netlify.

---

## 🖥️ Características principales

Entre Líneas cuenta con diferentes secciones que permiten navegar por el contenido del sitio.

### 🏠 Inicio

Página principal de la librería, donde se presenta la identidad visual de **Entre Líneas** y una selección de libros disponibles.

### 📚 Catálogo de libros

Permite visualizar diferentes libros disponibles dentro de la librería.

Cada libro cuenta con una página individual donde se muestra información más detallada.

### 📖 Detalle de libros

El proyecto incluye páginas específicas para cada libro del catálogo.

En ellas se presenta información como:

* Portada.
* Título.
* Autor.
* Descripción.
* Información relacionada con el libro.

### ✉️ Contacto

Incluí una página de contacto con un formulario que permite ingresar información como:

* Nombre.
* Correo electrónico.
* Número de teléfono.
* Mensaje.

El formulario forma parte de la interfaz visual del proyecto.

## 🚀 Cómo ejecutar el proyecto

Al tratarse de un sitio web estático, no es necesario instalar dependencias ni configurar un servidor.

### Opción 1 — Abrir directamente

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Buscar el archivo `index.html`.
4. Abrirlo con un navegador web.

### Opción 2 — Visual Studio Code

También puede ejecutarse utilizando la extensión **Live Server** de Visual Studio Code.

1. Abrir el proyecto en Visual Studio Code.
2. Instalar la extensión **Live Server**.
3. Hacer clic derecho sobre `index.html`.
4. Seleccionar **Open with Live Server**.
